# 飞书校园智能助手

杭电校园助手：在飞书里跟机器人聊天，查课表、校园卡、空教室、活动、图书馆，还能建提醒、订早报、发语音、联网搜索、读网页。

基于社团给的《飞书校园智能助手技术架构与Agent操作规划书》裁剪实现，只保留**真机跑通**的功能。

## 现在能干什么

共 36 个功能意图、15 个按钮，全部在飞书真机验证过。

**学习**

| 你说 | 它做 |
|---|---|
| 今天有啥课 / 明天有什么课 | 查今明两天课表（时间、教室、老师） |
| 这周有啥课 / 周三有啥课 | 查本周完整课表或某一天 |
| 下周有啥课 / 我下周课多吗 | 从整学期缓存按周号筛 |
| 这周和下周哪周课多 | 代码算两周节数差，给出对比 |
| 这学期有哪些课 | 11 门课 + 周次 + 学分 |
| 帮我做个期末复习计划 | 按课程学分/难度给复习安排 |
| 今天怎么安排 | 课表 + 天气 + 空教室综合成一段建议 |

**生活**

| 你说 | 它做 |
|---|---|
| 校园卡还有多少钱 | 实时余额 |
| 我这个月花了多少 | 消费流水分析（笔数、总额、常去店铺） |
| 宿舍还有多少电费 | 电费余额（绍信公寓 3-1005） |
| 今天天气怎么样 / 要带伞吗 | 天气 + 空气质量 + 代码生成的穿衣建议 |
| 图书馆有座位吗 | 自习室 / 生活区实时空位数 |
| 阳光长跑还差几次 | 有效次数、总里程、平均速度是否达标 |
| 最近有什么失物 | 校园失物招领（物品、地点、取物柜） |
| 杭电邮箱有几封未读 | IMAP 读 unread（网易企业邮） |

**空间与活动**

| 你说 | 它做 |
|---|---|
| 正心楼4楼空教室 / 青越有空教室吗 | **实时查**空闲教室（服务端现算，不用缓存） |
| 这周有啥活动值得去 | AI 从 10 个活动里挑 2-3 个相关的，附理由 |
| 周三的 AI 讲座我能去吗 | 代码比对活动时间和课表，0.6 秒出冲突结论 |
| 我报名了什么活动 | 诚实告知接口不支持，指向「青春杭电」 |
| 教务处办公地点在哪 | 查办公地点（**等 HDUHelp 知识库修复**） |

**助理**

| 你说 | 它做 |
|---|---|
| 明天早上8点提醒我交作业 | 建提醒，到点主动推送到飞书 |
| 我的提醒有哪些 / 取消提醒 3 | 管理提醒 |
| 每天 7 点半发早报 | 到点自动推「课表 + 天气 + 电费 + 当天待办」，关掉说「关掉早报」 |
| 课表图片 | 生成 1400px 彩色周课表 PNG 发出来 |
| 我要报名 XX 活动 | 查活动 → 弹确认卡片 → 点确认才真正提交 |
| 记住我住 3-1005 | 长期记忆，存 SQLite，重启不丢；「忘掉 3-1005」删 |
| 今天有什么新闻 | 联网搜索，标注来源和时间 |
| （直接发个链接） | 自动抓网页正文再回答，抓不到会如实说 |
| 今日速览 | 课表 + 余额 + 天气 + 待办，一条消息看完 |
| 你好 / 帮助 | 15 个按钮的功能菜单 |

**语音**：私聊里发语音，机器人先回「🎤 听到：xxx」再给答案。本地离线识别，不上传云端。

## 四个技术亮点

**1. 双模型：聊天和查数据用不同的模型**

- 聊天、写东西、读网页 → **DeepSeek V4.1 Flash**（1.4 秒，人设完整）
- 查校园数据 → **GLM-4-Flash**（免费，工具调用最稳）

为什么不一个模型全包：实测 GLM-4-Air 在强制调工具时会吐 XML 而不是标准 `tool_calls`；DeepSeek 默认开思考链，闲聊要等十几秒。分开各取所长。

**2. Agent function calling（不是关键词匹配）**

规则认不出的问法交给 Agent。多领域问题（"我今天有啥课、饭卡还有多少钱、天气怎么样"）会走循环：模型自己决定调哪几个工具，最多 2 轮。模型漏调时**代码强制补调**。

10 个工具：`query_schedule` `query_empty_rooms` `query_balance` `query_weather` `query_activities` `query_sunrun` `query_library` `query_knowledge` `web_search` `web_fetch`。

**3. 代码算数，AI 措辞**

节数、最忙的一天、时间冲突、消费总额，全部由 Python 算准，模型只负责组织成一句话。

这不是洁癖，是实测逼出来的：
- 让模型数节数 → 说"周一最忙"，实际周二 8 节最多
- 让模型看天气给建议 → 晴天说"记得带伞"
- 让模型判冲突 → 上午的课说和下午活动冲突

现在这三处都改成了纯代码判断。

**4. 空教室走服务端现算**

早期做法是拉全校 1089 间教室的占用存本地再算。实际踩坑：不同楼栋的周次不一致（正心楼是第 10 周、教研楼是第 1 周），本地算必错。

现在直接调 `academic classroom --building-id X --status unused --weekday N --section M`，服务端按教学楼自己的周次算好再返回。本地只缓存「楼名 → buildingID」索引（34 栋 / 1073 条名字），支持"青越"这种省略"楼"字的说法。

## LLM 配置（可选）

`.env` 里没配 `LLM_API_KEY` 时，LLM 兜底和 Agent 自动跳过，只走规则，不影响其余功能。

```dotenv
LLM_API_KEY=你的智谱Key
LLM_MODEL=glm-4-flash
LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
```

**成本**：GLM-4-Flash 目前免费（100 万 tokens/天）。按每天 50 次、每次 350 tokens 算，用不到额度的 2%。

## 怎么跑

> **双击启动**：根目录有 `★1 点我聊天.lnk`（命令行聊天）、`★2 启动飞书机器人.lnk`、`★3 重新授权.lnk`。
> **不要双击 `.py`** —— 这台电脑上 .py 关联到 PyCharm，双击会用 IDE 打开。

### 安装依赖

```bat
py -3 -m pip install -r requirements.txt
```

语音功能额外依赖 HuggingFace 上的 whisper tiny 模型（约 75MB），首次发语音时自动下载。国内会自动走 hf-mirror 镜像。

### 第一步：命令行聊天（不需要飞书）

双击 `★1 点我聊天.lnk`，或：

```bat
py -3 scripts/chat.py
```

### 第二步：批量测试

```bat
py -3 scripts/test_local.py
```

31 条用例，覆盖全部意图，不需要飞书、不花钱。

### 第三步：启动飞书机器人

1. 把 `.env.example` 复制成 `.env`
2. 填 `FEISHU_APP_ID` / `FEISHU_APP_SECRET`（飞书开放平台 → 凭证与基础信息）
3. 双击 `★2 启动飞书机器人.lnk`

窗口会一直开着——那是长连接保持中，关掉机器人就下线。

### 每学期开学跑一次

```bat
py -3 scripts/cache_schedule.py      :: 整学期课表（392 条，秒级）
py -3 scripts/cache_classrooms.py    :: 楼栋索引（1089 条，1-2 分钟）
```

不跑也能用今天/明天课表，只是没法查本周/整学期/空教室。

### 校园 API 授权

本项目通过 [hduhelp/cli](https://github.com/hduhelp/cli) 访问校园数据，需要设备授权：

```bat
C:\Users\lenovo\bin\hduhelp-cli.exe auth login --scope academic:read campuslife:read ...
```

授权链接 10 分钟有效。过期或要加权限时双击 `★3 重新授权.lnk`。

## 设计取舍

- **不做自建 RAG**：HDUHelp 有现成的知识检索接口，带溯源。自建要 4-6 小时，调接口 30 分钟——但接口目前在 500，等修。
- **不做 LangGraph**：意图路由用规则 + function calling 已够，还更好测。等规则写不下再上框架。
- **不做 MCP Server**：8 个工具都是 Python 函数，进程内直接调。MCP 适合多客户端共用，单机器人用不上。
- **写操作只做提醒**：提醒是本地 SQLite，风险可控。图书馆预约、活动报名涉及校内真实写接口，没做。

| 模型偶尔仍会编天气建议 | 提示词拦不住 | 代码删句兜底：工具没给"伞"就从回答里删掉整句 |

## 中文路径问题

项目放在含中文和空格的路径下（比如桌面上的中文文件夹）。

- ✅ Python 跑脚本：正常
- ✅ `.lnk` 快捷方式：用绝对路径调 py，绕开 cd
- ❌ `.bat` 里的 `cd /d "中文路径"`：cmd 会报「文件名、目录名或卷标语法不正确」

如果快捷方式还是没反应，把整个项目移到纯英文路径（如 `D:\campus-feishu-agent`）即可。代码全部用 `Path(__file__)` 定位，不依赖固定路径。
